# Baby Sleep Sync

Mobile-first PWA for two parents to share a baby sleep schedule in real time.

- Shared household and invite code
- Supabase realtime sync
- 3 / 3.5 / 4 wake-window targets
- 5 / 3 / 3 night-feed windows
- Editable rules and history
- Android installable PWA

The browser uses only the Supabase publishable key. Do not add any Supabase secret/service-role key to this repository.
